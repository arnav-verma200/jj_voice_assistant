                    JJ VOICE ASSISTANT - SETUP GUIDE
================================================================================

Thank you for downloading JJ Voice Assistant! This guide will help you get 
started with your voice-controlled browser automation assistant.

================================================================================
PREREQUISITES
================================================================================

Before running JJ Voice Assistant, please ensure you have:

✅ Windows 10 or later
✅ Google Chrome (Download: https://www.google.com/chrome/)
✅ Spotify Desktop App (Download: https://www.spotify.com/download/)
✅ Microphone (for voice input modes)
✅ Webcam (for gesture volume control feature)
✅ WhatsApp on your phone (for messaging features)

================================================================================
QUICK START
================================================================================

1. CHOOSE YOUR VERSION
   
   • jj_voice_assistant_cli.exe - Command-line interface (simple, lightweight)
   • jj_voice_assistant_gui.exe - Graphical interface (easier to use)
   
   Both versions have the same features. Choose based on your preference!

2. FIRST RUN
   
   • Double-click the .exe file you want to use
   • Windows Defender may show a warning (this is normal for new executables)
   • Click "More info" → "Run anyway" to proceed
   
3. SELECT INPUT MODE
   
   You'll be asked to choose how to control the assistant:
   
   Option 1 - Continuous Voice (Always Listening)
      • Say "jj" before each command
      • Example: "jj play despacito in spotify"
      • Press ESC to stop
   
   Option 2 - Button Voice (Press to Talk)
      • Hold SPACE bar to speak
      • Say "jj" before each command
      • Release SPACE when done
   
   Option 3 - Typing
      • Type commands manually
      • No need to say "jj"

4. FIRST-TIME SETUP
   
   When you run the assistant for the first time:
   
   a) Chrome will open automatically
      • Sign in to your Google account
      • Your login will be saved for future sessions
   
   b) For WhatsApp features:
      • First WhatsApp command opens WhatsApp Web
      • Scan the QR code with your phone
      • Your session will persist across restarts

================================================================================
OPTIONAL: ENABLE AI FEATURES
================================================================================

JJ Voice Assistant can use Google's Gemini AI for smarter website detection.
This is OPTIONAL - the assistant works without it, but AI makes it better!

TO ENABLE AI FEATURES:

1. Get a FREE API key:
   • Visit: https://makersuite.google.com/app/apikey
   • Sign in with Google account
   • Click "Create API Key"
   • Copy the key

2. Create a .env file:
   • Open Notepad
   • Type: GEMINI_API_KEY=your_api_key_here
   • Replace "your_api_key_here" with your actual key
   • Save as ".env" (with quotes) in the same folder as the .exe file
   
   Example .env file content:
   GEMINI_API_KEY=AIzaSyABC123def456GHI789jkl012MNO345pqr

3. Restart the assistant

Without AI: Basic website detection still works for common sites
With AI: Smarter detection for 1000+ websites and apps

================================================================================
AVAILABLE COMMANDS
================================================================================

🎵 SPOTIFY COMMANDS
   play <song> in spotify       - Play a song
   spotify pause/play           - Control playback
   spotify next/previous        - Skip tracks
   pause / next / previous      - Quick controls
   open spotify                 - Launch Spotify app

🎥 YOUTUBE COMMANDS
   play <video> in youtube      - Play a video
   open youtube                 - Open YouTube

💬 WHATSAPP COMMANDS
   message <contact>            - Send WhatsApp message
                                  (Selects first search result!)

🌐 BROWSER COMMANDS
   search <query>               - Google search
   open <website>               - Open any website
                                  Examples: open youtube, open github

🎚️ VOLUME CONTROL
   volume control               - Start gesture control
   stop volume                  - Stop gesture control
   
   How it works:
   • Pinch thumb and index finger together
   • Move fingers apart = louder
   • Move fingers closer = quieter

🚪 EXIT
   exit                         - Close the assistant

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Chrome not found" error
SOLUTION: Install Chrome from https://www.google.com/chrome/
          Make sure it's installed in the default location

PROBLEM: Spotify commands don't work
SOLUTION: Install Spotify Desktop App (not web player)
          Download: https://www.spotify.com/download/

PROBLEM: Voice recognition not working
SOLUTION: • Check microphone is connected and working
          • Allow microphone access when prompted
          • Speak clearly and at normal volume
          • Make sure to say "jj" before commands

PROBLEM: Volume control doesn't work
SOLUTION: • Check webcam is connected
          • Allow camera access when prompted
          • Ensure good lighting
          • Pinch thumb and index finger clearly

PROBLEM: WhatsApp messages go to wrong person
SOLUTION: WhatsApp ALWAYS selects the first search result
          Use distinctive names to avoid confusion

PROBLEM: Windows Defender blocks the .exe
SOLUTION: This is a false positive (common with PyInstaller)
          Click "More info" → "Run anyway"
          Or add an exception in Windows Security

PROBLEM: "API key not found" message
SOLUTION: This is just a warning - AI features are optional
          The assistant still works without an API key
          To enable AI, follow the "Enable AI Features" section above

================================================================================
TIPS FOR BEST EXPERIENCE
================================================================================

✨ First time using WhatsApp or Google features? 
   Sign in when Chrome opens - your login is saved!

✨ Make sure Spotify Desktop is installed for music playback
   Web player won't work with keyboard controls

✨ Volume control needs good lighting for webcam
   Position yourself so the camera can see your hand clearly

✨ WhatsApp always messages the FIRST person in search results
   Use full names or unique nicknames to avoid mistakes

✨ Voice mode works best in quiet environments
   Background noise can interfere with recognition

PRIVACY & DATA
================================================================================

🔒 All data stays on YOUR computer
   • Chrome sessions stored locally in %USERPROFILE%\ChromeAutomation
   • No credentials sent to external servers
   • API key (if used) only communicates with Google's Gemini API

🗑️ To clear saved sessions:
   Delete the folder: %USERPROFILE%\ChromeAutomation
